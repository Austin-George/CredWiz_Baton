# Project Name

## Overview

Project Name is a CredWiz. It is a wallet like application using Spring Boot.

This project is part of my internship learning about Spring boot and React.

## Features

- User can create account and manage the CredWiz account
- User can add bank account details and create a wallet
- User can add money in to the wallet and use it for the payments

## Technologies Used

- Languages: Java, JavaScript, SQL
- Tools: MySQL, Maven, Docker
- Libraries & Frameworks: Spring, Spring Boot, ReactJs
